# Rough Idea

Create a rust based notes app, for mac os (intel and apple silicon) where:

0. notes are in html/js only
1. initialize the application by loading notes from a folder. this happens once when setting up the app the first time.
2. 2 panel design; show the list of notes heading on the left side. render the actual notes on the right side.
3. render the notes on the right side using some existing open source browser framework

Browser engine decision under consideration: webkit
